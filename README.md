# Кормушка кота: установка за ~30 минут

Приложение для всей семьи на Android и iPhone: кто, когда и чем покормил кота, и push-уведомление «Кот голоден», если с последней кормёжки прошло больше 6 часов.

**Что понадобится:** компьютер с браузером и аккаунт Google. Программировать не нужно, только нажимать кнопки и копировать текст. **Стоимость:** 0 €, бесплатных тарифов Firebase и GitHub для семьи хватает с огромным запасом.

**Как это устроено:**
- **Firebase (Google)** хранит общие записи и рассылает уведомления.
- **GitHub** хранит файлы приложения, раздаёт его по ссылке и каждые 30 минут проверяет, не голоден ли кот.

---

## Шаг 1. Создать проект Firebase

1. Откройте **https://console.firebase.google.com** и войдите аккаунтом Google.
2. **«Создать проект»** (Create a project) → название `kormushka` → Google Analytics **отключите** → «Создать проект».
3. Меню слева **Build → Authentication** → «Начать» (Get started) → вкладка **Sign-in method** → **Anonymous** → включить → «Сохранить».
4. Меню слева **Build → Firestore Database** → «Создать базу данных»:
   - расположение: **eur3 (europe-west)**;
   - режим: **Production mode** → «Создать».
5. В Firestore откройте вкладку **Rules** (Правила), удалите всё, что там есть, вставьте содержимое файла `firestore.rules` из архива и нажмите **«Опубликовать»** (Publish).

## Шаг 2. Получить ключи

Нажмите шестерёнку рядом с «Обзор проекта» → **«Настройки проекта»** (Project settings).

1. Вкладка **«Общие»** (General) → внизу «Ваши приложения» → значок **`</>`** (Web):
   - псевдоним `kormushka`, галочку Hosting **не ставить** → «Зарегистрировать приложение»;
   - появится блок `const firebaseConfig = { apiKey: "...", ... }`. Оставьте страницу открытой, эти значения понадобятся на шаге 3.
2. Вкладка **Cloud Messaging** → раздел **Web configuration / Web Push certificates** → **«Generate key pair»**. Скопируйте длинный ключ.
3. Вкладка **«Сервисные аккаунты»** (Service accounts) → **«Сгенерировать новый закрытый ключ»** → скачается файл `.json`.
   > ⚠️ Это секретный ключ. Никому не отправляйте его и не загружайте в файлы приложения. Он понадобится только на шаге 6.

## Шаг 3. Заполнить config.js

1. Распакуйте архив `kormushka.zip`.
2. Откройте файл `config.js` в Блокноте (Windows: правой кнопкой → «Открыть с помощью» → Блокнот; Mac: TextEdit).
3. Замените каждое `ВСТАВЬТЕ_СЮДА` на значения из шага 2:
   - `apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId`, `appId` из блока firebaseConfig;
   - `vapidKey`: ключ из Cloud Messaging.

   Кавычки оставьте, меняется только текст внутри них. Сохраните файл.

## Шаг 4. Выложить приложение на GitHub

1. Зарегистрируйтесь на **https://github.com** (бесплатно). Запомните своё имя пользователя.
2. Справа вверху **«+» → New repository**:
   - Repository name: `kormushka`;
   - **Public**;
   - больше ничего не отмечать → **Create repository**.
3. На открывшейся странице нажмите ссылку **«uploading an existing file»**.
4. Перетащите в окно **всё содержимое** распакованной папки: `index.html`, `app.js`, `config.js`, `firebase-messaging-sw.js`, `manifest.webmanifest`, `cat.jpg`, `firestore.rules`, `README.md` и папки `icons` и `notifier`. Нажмите **Commit changes**.
5. Папку `.github` браузер обычно не загружает, потому что она скрытая. Создайте её вручную:
   - **Add file → Create new file**;
   - в поле имени напишите ровно `.github/workflows/hungry.yml`; косые черты сами создадут папки;
   - откройте файл `hungry.yml` из архива (папка `.github/workflows`) в Блокноте, скопируйте всё и вставьте;
   - **Commit changes**.
6. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**.
7. Через 1–2 минуты приложение будет доступно по адресу:
   **`https://ВАШЕ-ИМЯ.github.io/kormushka/`**

## Шаг 5. Создать семью

1. Откройте этот адрес на своём телефоне.
2. Нажмите **«Создать семью»**.
3. Откройте **Настройки** (кнопка справа вверху):
   - впишите имя кота и имена всех четырёх членов семьи → «Сохранить»;
   - в блоке «Пригласить семью» есть **ссылка** и **код**. Код понадобится на шаге 6.

## Шаг 6. Включить проверку «Кот голоден»

На GitHub в репозитории `kormushka`: **Settings → Secrets and variables → Actions → New repository secret**. Создайте два секрета:

| Name | Secret |
|---|---|
| `FIREBASE_SERVICE_ACCOUNT` | откройте скачанный на шаге 2.3 файл `.json` в Блокноте, скопируйте **весь** текст и вставьте |
| `FAMILY_ID` | код семьи из настроек приложения (шаг 5) |

Затем проверьте, что всё работает:

1. Вкладка **Actions**. Если появится кнопка «I understand my workflows, go ahead and enable them», нажмите её.
2. Слева **«Кот голоден?»** → **Run workflow** → **Run workflow**.
3. Через минуту должна появиться зелёная галочка ✅.

После этого проверка работает сама каждые 30 минут.

## Шаг 7. Установить на телефоны всей семьи

Отправьте **ссылку-приглашение** из настроек супруге и детям (WhatsApp, Telegram и т. п.).

**Android (Chrome):**
1. Откройте ссылку.
2. Меню ⋮ → **«Установить приложение»** или «Добавить на главный экран».
3. Откройте приложение с иконки.
4. Выберите себя в «Кто кормит» и нажмите **«Включить уведомления»** → «Разрешить».

**iPhone (iOS 16.4 или новее, только Safari):**
1. Откройте ссылку **в Safari**.
2. Кнопка «Поделиться» □↑ → **«На экран „Домой“»** → «Добавить».
3. Откройте приложение **с иконки на главном экране**. Если оно попросит код семьи, вставьте код из ссылки: это всё, что идёт после `#fam=`.
4. Выберите себя и нажмите **«Включить уведомления»** → «Разрешить».

> На iPhone уведомления работают только в приложении, открытом с главного экрана, а не во вкладке Safari.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| «Приложение ещё не настроено» | В `config.js` осталось `ВСТАВЬТЕ_СЮДА`. Исправьте: на GitHub откройте файл → карандаш ✏️ → исправить → Commit. |
| «Не удалось подключиться» | В Firebase не включён анонимный вход (шаг 1.3). |
| «Нет доступа к данным» | Правила Firestore не опубликованы (шаг 1.5). |
| Уведомления не приходят | Проверьте вкладку Actions: последний запуск должен быть зелёным. Если красный, откройте его: в журнале будет написано, какой секрет не задан. |
| Через 2 месяца проверка остановилась | Если в репозитории 60 дней ничего не менялось, GitHub отключает расписание и присылает письмо. Откройте Actions → «Кот голоден?» → **Enable workflow**. |
| Хочу другое время «голода» | 6 часов задано в двух местах: `config.js` (`hungryHours`) и `.github/workflows/hungry.yml` (`HUNGRY_HOURS`). Поменяйте в обоих. |

## Безопасность

Данные семьи доступны только тому, у кого есть код семьи: 20 случайных символов, подобрать невозможно. Не публикуйте ссылку-приглашение в открытом доступе. Секретный ключ `.json` хранится только в секретах GitHub.
